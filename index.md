# AmazingHiring API

AmazingHiring exposes two public APIs. Each one has its own access token, issued after
approval from your [AmazingHiring sales manager](mailto:sales@amazinghiring.com).

* **[AmazingHiring API v6](api-v6.md)** — integration of AmazingHiring with your product:
  read profiles, and manage folders and the candidates in them.
  \([Swagger UI](https://search.amazinghiring.com/api/v6/docs/)\)

* **[Data Enrichment API](data-enrichment.md)** — an email, a phone, a link or a profile
  id in, a full AmazingHiring profile out. Asynchronous: create a request, then poll it
  or receive a callback.
  \([Swagger UI](https://search.amazinghiring.com/api/dataenrichment/docs)\)
